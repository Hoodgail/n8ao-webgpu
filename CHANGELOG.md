# Changelog

## 1.0.0

- Native Three.js r186 WebGPU rendering with TSL shader graphs.
- Modular TypeScript API with strict declarations and class-owned resources.
- Bilateral and neural filtering with an extensible denoiser interface.
- Full and half resolution, accumulation, transparency and depth-mode support.
- Interactive documentation and six procedural examples.
- Unit tests and 45 native WebGPU visual regression fixtures.

This release is derived from N8AO 2.0.1. See the compatibility guide for differences from the original WebGL renderer.
