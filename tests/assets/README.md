# Rendering fixtures

`sponza.glb` is preserved from N8AO's test assets at revision
`0fc15550c98119758e83ed4c2d0e87273bae9ed9`.

The Sponza atrium originated with Marko Dabrovic; the extended model is by
Crytek. See the [glTF Sponza attribution](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Sponza)
and accompanying `Sponza-LICENSE.md` for contributor and license details.

`draco/` contains the decoder needed by the compressed fixture, with its
Apache-2.0 license. These files are used by tests only, not by the example site
or distributed npm package. All website example geometry is procedural.
